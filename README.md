# Expense Tracker

A React application to track daily expenses using forms, tables, and filtering.

## Live Demo

https://lustrous-youtiao-fe162a.netlify.app/
## Features

- View all expenses
- Add new expenses
- Filter expenses by description
- Sort by description or category
- Delete individual expenses

## Installation

git clone https://github.com/Elvis108-coder/expense-tracker.git  
cd expense-tracker  
npm install  
npm run dev  

## Deployment

Build command: `npm run build`  
Publish directory: `dist`  
Deployed on Netlify
